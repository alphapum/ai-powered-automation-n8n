## หมวดที่ใช้ใน Workshop (4 หมวด)

1. `ค่าวัสดุสำนักงาน` — กระดาษ, ปากกา, หมึก, อุปกรณ์
2. `ค่าเดินทาง` — taxi, BTS, น้ำมัน, ที่พัก
3. `ค่าอบรม/สัมมนา` — ลงทะเบียน course, สื่อการสอน
4. `ค่ารับรอง/อาหารว่าง` — กาแฟประชุม, ของว่าง

> ในงานจริงอาจมีมากกว่านี้ — แต่ใน workshop เราใช้ 4 หมวดให้ AI สรุปไม่ยาว

## วิธีเตรียม Sheet ของตัวเอง (ถ้าไม่ใช้ template)

ถ้าจะสร้างเอง:

1. เปิด **Google Sheets** → สร้าง spreadsheet ใหม่
2. ตั้งชื่อ **`W5 Expenses - [ชื่อคุณ]`**
3. ที่แถวแรก (Row 1) ใส่ header ตามลำดับ:
   ```
   date | category | description | amount | requester | approver | status | receipt_url
   ```
4. Copy 10 rows ด้านบนวางในแถว 2-11
5. **สำคัญ:** เซลล์ `amount` ต้องเป็น Number — Format → Number → Plain Number

> ⚠️ ถ้า `amount` เป็น text — Code node จะแปลงด้วย `Number()` ให้ใน Step 5

## เอาไปปรับใช้กับงานคุณ

ลองคิดดู — Sheet งานคุณมี structure อะไรที่ใช้ pattern นี้ได้?

| Sheet ของคุณ | คอลัมน์หลัก | "category" ของคุณ | AI สรุปอะไร |
|--------------|-------------|-------------------|--------------|
| คำร้องนิสิต | ประเภทคำร้อง | ลาเรียน/ใบรับรอง/อื่นๆ | ประเภทที่เยอะ |
| ตารางสอน | รายวิชา | สาขา/ระดับ/อาจารย์ | load อาจารย์ |
| ใบลา | ประเภทลา | ลาป่วย/กิจ/พักร้อน | คนลาเยอะ |
| ยอดขาย | สินค้า | ประเภท/แบรนด์ | สินค้าขายดี |
| ใบเสร็จ vendor | vendor | ประเภทบริการ | vendor หลัก |

> 💡 **Pattern หลัก:** ข้อมูลในตารางที่มี "column ใช้จัดกลุ่มได้" (category) + "column ที่มีตัวเลขรวมได้" (amount) = candidate สำหรับ Workshop 5 pattern
