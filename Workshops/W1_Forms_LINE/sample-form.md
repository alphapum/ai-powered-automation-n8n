# Workshop 1: Google Form Template

โครงสร้าง Google Form ที่ใช้ใน Workshop 1 — TA จะแจก link template ในห้อง

## ข้อมูลพื้นฐาน

- **ชื่อฟอร์ม:** คำร้องนิสิต — KU Workshop n8n
- **คำอธิบาย:** ฟอร์มทดลองสำหรับ workshop n8n — ส่งคำร้องของคุณ จะได้รับการแจ้งเตือนผ่าน LINE

## คำถามในฟอร์ม

### 1. ชื่อ-นามสกุล *(Required)*
- **Type:** Short answer
- **Validation:** None
- **Example:** `สมชาย ใจดี`

### 2. รหัสนิสิต *(Required)*
- **Type:** Short answer
- **Validation:** Regex `^\d{7}$` (7 หลัก)
- **Example:** `6500000`

### 3. เรื่องที่ขอ *(Required)*
- **Type:** Dropdown
- **Options:**
  - `ลาเรียน`
  - `ขอใบรับรอง`
  - `ขอเปลี่ยนสาขา`
  - `ขอผ่อนผันค่าเทอม`
  - `อื่นๆ`

### 4. รายละเอียด *(Optional)*
- **Type:** Paragraph
- **Description:** "อธิบายเหตุผล หรือข้อมูลเพิ่มเติม (ถ้ามี)"
- **Example:**
  ```
  ขอลาเรียนวันที่ 1-3 มิถุนายน เพื่อไปงานศพคุณยาย
  มีใบเตรียมมาให้แล้วครับ
  ```

## ตั้งค่าเพิ่มเติม

- **Collect email addresses:** Off (เพื่อให้ test ง่าย)
- **Limit to 1 response:** Off
- **Show progress bar:** Off
- **Shuffle question order:** Off

## ตัวอย่าง JSON ที่ Webhook จะได้รับ

หลังจาก Apps Script ส่งมา n8n จะได้รับ:

```json
{
  "timestamp": "2026-05-26T13:45:23.456Z",
  "name": "สมชาย ใจดี",
  "student_id": "6500000",
  "topic": "ลาเรียน",
  "detail": "ขอลาเรียนวันที่ 1-3 มิถุนายน..."
}
```

## ตัวอย่างข้อความที่จะส่งเข้า LINE

```
📩 คำร้องใหม่จาก: สมชาย ใจดี
รหัส: 6500000
เรื่อง: ลาเรียน

รายละเอียด:
ขอลาเรียนวันที่ 1-3 มิถุนายน...
```

## เอาไปปรับใช้กับงานคุณ

ลองคิดดู — งานของคุณมีฟอร์มอะไรบ้างที่จะเอามาทำแบบนี้ได้?

| งาน | คำถามในฟอร์ม | ส่งไปไหน |
|-----|--------------|---------|
| ฟอร์มจองห้องประชุม | ห้อง / วันเวลา / ผู้จอง | LINE คนดูแลห้อง |
| ฟอร์มแจ้งซ่อม | ที่ตั้ง / ปัญหา / รูป | LINE ช่าง |
| ฟอร์มขอเอกสาร | ประเภท / นิสิต | LINE เจ้าหน้าที่ |
| ฟอร์มข้อเสนอแนะ | หัวข้อ / รายละเอียด | LINE ผู้บริหาร |
