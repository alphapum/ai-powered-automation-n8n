## Import + ต้องแก้ 4 จุด

หลัง import — ต้องเปลี่ยน 4 ค่าเป็นของคุณเอง:

1. **Gmail credential** (ใช้ 3 ที่ — Gmail search / Gmail download / Gmail mark read) — ใส่ของคุณ
2. **Drive credential** — ใส่ของคุณ
3. **Drive folder ID** — เลือกโฟลเดอร์ปลายทางใน Drive
4. **Schedule interval** — ถ้าจะ test เร็วๆ ตั้งเป็น 1 minute, ของจริงควรเป็น 15 minutes
